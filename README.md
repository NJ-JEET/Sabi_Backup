# Plataforma Web de Gestión Médica (Sabi)
Sistema integral diseñado para la optimización de citas médicas, administración de expedientes y gestión eficiente de especialistas de la salud.

## 🚀 Alcance del Proyecto (Sprint 1)
* **Autenticación Segura:** Módulo de registro e inicio de sesión con control de accesos basado en roles para pacientes y especialistas médicos.
* **Arquitectura de Datos:** Diseño, refactorización e implementación del esquema relacional de bases de datos para garantizar la integridad de la información de los usuarios.
* **Migración y Despliegue:** Preparación de tablas y entornos lógicos optimizados para producción.

## 🛠️ Tecnologías Utilizadas
* **Backend & Framework:** PHP / Laravel
* **Estilos & UI:** Tailwind CSS / Bootstrap
* **Base de Datos:** MariaDB / MySQL
* **Gestión de Proyecto:** Jira / Asana (Metodología Ágil / Scrum)

## 👥 Equipo de Desarrollo
* **Líder de Desarrollo:** Co-ingeniería de backend y control de versiones.
* **Equipo:** Colaboración estrecha con analistas, desarrolladores y testers para asegurar entregas constantes de valor.
